## 发现
- **[轻微]** — `ScheduleConflictPolicy` 的集合方法同时规定“任一元素为 `null` 时抛出 `NullPointerException`”和“任一冲突即返回 `true`”。该契约可实现，但编码时需要注意不要因为先遇到冲突元素就短路，从而漏掉后续 `null` 元素；建议测试覆盖“冲突元素之前/之后存在 `null`”的情况。
- **[轻微]** — `ScheduleStatus.displayName()` 使用 `"进行中"`，需求文本中也出现过“正常进行”表述。当前设计在任务上下文的动态状态规则中使用“进行中”，不影响正确性；后续控制台展示如需统一文案，应以本设计的稳定展示文本为准。
