# 计划审查报告（v17 r1）

## 审查结果
REJECTED

## 发现

- **[一般]** — `LocalContext` 的公开结构没有收束到唯一可实现契约。任务只说明它“可包含 `DashboardSummary` 以及由汇总结果生成的简短文本字段或结构化字段”，并要求空数据、单模块数据和多模块数据有稳定表示，但没有固定字段名称、字段类型、文本生成口径或结构化摘要边界。后续 `assistant.ai` 的 `PromptBuilder`、AI 问答和摘要测试会直接依赖 `LocalContext`，如果本轮由 Designer/Coder 自由选择文本或结构字段，下一轮很容易出现提示词构造无法稳定断言、上下文字段不足或需要再次改动公开 API 的问题。

## 修改要求（仅 REJECTED 时）

- 针对 `LocalContext` 明确唯一公开形态和稳定内容口径。建议在 `task_v17.md` 中固定为一个 record，例如至少包含 `DashboardSummary dashboardSummary` 和若干确定的非空文本/结构字段，并明确每个字段如何由汇总结果生成、空数据如何表达、列表/映射是否复制为不可修改快照、测试需要覆盖哪些稳定断言。不要继续使用“可包含”“简短文本字段或结构化字段”这类开放描述，让后续设计和 AI 模块只能沿同一契约实现。
