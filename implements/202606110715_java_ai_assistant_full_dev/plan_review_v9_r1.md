## 发现
- **[轻微]** — 任务上下文提到冲突拒绝保存并返回 `SCHEDULE_CONFLICT`，但本轮明确不实现 `ScheduleService` 和仓储，因此该错误码转换只能作为后续服务层上下文，不能由本轮领域模型完整交付。当前任务文件已把本轮范围限定为实体、状态和冲突策略，并未要求本轮实现保存路径，因此不影响可执行性。
- **[轻微]** — `ScheduleConflictPolicy` 被要求处理候选日程与既有集合的冲突，但未固定返回冲突对象、布尔值或抛异常等 API 形态。该细节可由设计阶段结合后续服务需求确定，当前计划已足以约束核心冲突语义：复用左闭右开重叠规则、首尾相接不冲突、空入参拒绝。
