## 行为覆盖

### ConsoleApplication 任务子菜单

- 主菜单命令 `2` 进入任务子菜单，返回后主菜单其他入口仍可继续执行。
- 任务子菜单展示核心命令说明：列表、新增、查看、筛选、修改、完成、撤销完成、删除、返回和帮助。
- 空数据任务列表输出 `暂无任务`。
- 新增任务成功后输出任务详情，列表可见新增项，汇总可反映今日任务数。
- 查看、修改、删除任务的成功路径可见；删除后查看返回 `NOT_FOUND`。
- 完成任务输出 `COMPLETED`，重复完成输出 `STATE_CONFLICT`，撤销完成后输出 `TODO`。
- 筛选可按状态、优先级和截止日期组合匹配，并排除非匹配任务。
- 筛选的状态、优先级和截止日期均为空时，按无筛选条件列出全部任务。
- 非法任务 id、非法截止日期、非法优先级和非法筛选状态均输出 `VALIDATION_ERROR`，并保持既有数据不被错误写入。
- 未知任务命令输出提示并展示帮助；空任务命令输出 `请输入任务命令。`，随后仍留在任务子菜单继续处理列表命令。
- 任务命令读取 EOF 和新增字段中途 EOF 均可正常结束，不创建半成品任务。
- 任务列表服务失败时，控制台输出服务返回的错误码和消息。
