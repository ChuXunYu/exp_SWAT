# 验收清单与下一阶段迭代计划

本文档面向课程项目验收者、开发者和后续迭代执行者，基于当前仓库中已经完成的 `java-ai-assistant/` 工程整理产品级验收清单和下一阶段迭代计划。当前版本是 Java 17、Maven 单模块、单用户、本地运行、命令行交互的 AI 个人学习与生活助手。业务数据默认保存在内存仓储中，普通单元测试不依赖真实 DeepSeek、网络、API Key 或真实当前时间。

本文档不重新定义需求语义，而是在既有需求、架构设计、技术方案、实现计划和当前代码交付状态基础上，明确当前版本交付范围、可执行验收项、异常验收项、非功能验收项、范围边界和下一阶段优先级。

## 用户视角核心场景验收清单

| 编号 | 验收场景 | 前置条件或输入 | 操作或检查方式 | 预期结果 |
|------|----------|----------------|----------------|----------|
| A1 | 启动命令行程序 | 已安装 Java 17 和 Maven | 在 `java-ai-assistant/` 构建 classpath 后运行 `assistant.app.Main` | 控制台显示主菜单，包含汇总、任务、日程、学习计划、收支、笔记、AI 问答、AI 草稿、帮助和退出入口。 |
| A2 | 查看汇总 | 使用默认演示数据或手工创建数据 | 在主菜单选择汇总入口 | 显示今日任务、今日日程、本周学习计划、本月收入/支出/结余、笔记数量和标签分布。 |
| A3 | 任务完整生命周期 | 输入合法标题、描述、优先级和截止日期 | 创建任务，查看详情，修改基础信息，标记完成，撤销完成，再删除 | 每一步返回成功结果；完成状态和筛选结果同步变化；删除后再次查看返回 `NOT_FOUND`。 |
| A4 | 任务筛选 | 已存在不同状态和优先级的任务 | 按状态、优先级或截止日期筛选 | 返回符合条件的只读任务视图，不暴露内部可变实体。 |
| A5 | 日程创建与按日期查询 | 输入名称、开始时间、结束时间、地点和备注 | 创建日程，再按自然日查询 | 返回覆盖该日期的日程；状态由当前时间动态计算。 |
| A6 | 日程冲突识别 | 已存在某一时间段日程 | 创建与其时间重叠的新日程，再创建首尾相接的新日程 | 重叠日程返回 `SCHEDULE_CONFLICT`；首尾相接日程允许创建。 |
| A7 | 日程状态 | 使用可控当前时间 | 分别查询未开始、进行中、已结束日程 | 状态分别显示即将开始、进行中、已过期。 |
| A8 | 学习计划进度 | 输入合法目标、开始日期、截止日期和预期投入 | 创建计划，更新进度为 0、50、100 | 0 和中间值保持未完成或进行中语义；100 识别为完成；统计数量同步更新。 |
| A9 | 学习计划逾期 | 当前日期晚于截止日期且进度未满 | 查询计划状态或本周计划 | 返回逾期或未完成状态，不依赖真实系统日期。 |
| A10 | 收入和支出统计 | 输入多笔收入和支出，含不同类别和日期 | 按类别、日期范围查询并计算统计 | 收入总额、支出总额和结余与手工计算一致，金额保留两位小数。 |
| A11 | 删除后统计同步 | 已存在收支记录 | 删除一笔记录后重新计算统计 | 统计结果基于当前仓储数据重新计算，不保留已删除记录影响。 |
| A12 | 笔记管理 | 输入合法标题、内容和标签 | 新增、查看、修改、按关键字查询、按标签查询、删除 | 查询结果符合标题/内容大小写不敏感匹配和标签归一语义；删除后返回 `NOT_FOUND`。 |
| A13 | AI 问答无 Key 行为 | 未配置 `DEEPSEEK_API_KEY` | 进入 AI 问答并提交问题 | 返回 `AI_NOT_CONFIGURED` 或等价未配置提示，本地任务、日程、计划、收支、笔记功能仍可继续使用。 |
| A14 | AI 问答 mock 行为 | 单元测试使用 fake 或 mock AI 客户端 | 构造问题和本地上下文后调用 AI 服务 | 请求包含场景、用户问题和本地摘要；成功响应可展示；失败响应映射为稳定错误码。 |
| A15 | AI 草稿确认导入 | 已存在可确认的任务或学习计划草稿 | 查看草稿并执行确认导入 | 草稿状态变为 `IMPORTED`，正式任务或学习计划新增成功。 |
| A16 | AI 草稿取消导入 | 已存在可确认草稿 | 执行取消，再尝试确认 | 取消不修改正式业务数据；取消后确认返回 `STATE_CONFLICT`。 |
| A17 | 重复确认草稿 | 已确认导入的草稿 | 再次执行确认导入 | 返回 `STATE_CONFLICT`，正式业务数据不会重复新增。 |

## 异常场景验收清单

| 异常类别 | 输入或操作 | 预期错误分类或可观察结果 | 数据一致性要求 |
|----------|------------|--------------------------|----------------|
| 空任务标题 | 创建或修改任务时标题为空白 | `VALIDATION_ERROR` | 不新增或不修改原任务。 |
| 非法任务状态迁移 | 重复完成或重复撤销完成 | `STATE_CONFLICT` | 任务状态保持原值。 |
| 不存在任务 | 查看、修改、删除、完成不存在 id | `NOT_FOUND` | 仓储数据不变。 |
| 空日程名称 | 创建或修改日程名称为空白 | `VALIDATION_ERROR` | 不新增或不修改原日程。 |
| 非法日程时间 | 结束时间不晚于开始时间 | `VALIDATION_ERROR` | 不新增或不修改原日程。 |
| 日程冲突 | 创建或修改为已有日程重叠时间段 | `SCHEDULE_CONFLICT` | 已有日程不变，新日程不写入。 |
| 学习计划空目标 | 创建或修改目标为空白 | `VALIDATION_ERROR` | 不新增或不修改原计划。 |
| 学习计划日期非法 | 开始日期晚于结束日期 | `VALIDATION_ERROR` | 不新增或不修改原计划。 |
| 学习进度越界 | 进度小于 0 或大于 100 | `VALIDATION_ERROR` | 原计划进度不变。 |
| 非法金额 | 金额为 0、负数、超过两位小数或无法解析 | `VALIDATION_ERROR` | 不新增或不修改收支记录。 |
| 未知或空收支类型 | 类型为空或无法识别 | `VALIDATION_ERROR` | 不新增或不修改收支记录。 |
| 收支日期范围非法 | 查询开始日期晚于结束日期 | `VALIDATION_ERROR` | 已有收支记录不变。 |
| 空笔记标题或内容 | 新增或修改笔记时标题/内容为空白 | `VALIDATION_ERROR` | 不新增或不修改原笔记。 |
| 空关键字 | 按关键字查询时关键字为空白 | `VALIDATION_ERROR` | 笔记数据不变。 |
| 不存在笔记 | 修改或删除不存在 id | `NOT_FOUND` | 笔记数据不变。 |
| 非法标签 | 标签为空或集合中包含非法标签 | `VALIDATION_ERROR` | 原标签集合不变。 |
| AI 未配置 | 未提供 API Key 发起真实 AI 问答 | `AI_NOT_CONFIGURED` | 本地业务数据不变，本地功能可继续使用。 |
| AI 鉴权失败 | 远端返回 401 或 403 | `AI_AUTH_FAILED` | 本地业务数据不变。 |
| AI 限流 | 远端返回 429 | `AI_RATE_LIMITED` | 本地业务数据不变。 |
| AI 超时 | 网络超时、408 或 504 | `AI_TIMEOUT` | 本地业务数据不变。 |
| AI 远端不可用 | 远端返回 5xx | `AI_REMOTE_UNAVAILABLE` | 本地业务数据不变。 |
| AI 空响应 | HTTP 成功但内容为空 | `AI_EMPTY_RESPONSE` | 不生成草稿，不修改业务数据。 |
| AI 格式异常 | 结构化建议 JSON 缺字段、类型错误或无法解析 | `AI_MALFORMED_RESPONSE` | 不生成可确认草稿，不修改业务数据。 |
| 草稿取消后确认 | 对 `CANCELLED` 草稿确认导入 | `STATE_CONFLICT` | 正式业务数据不变。 |
| 草稿重复确认 | 对 `IMPORTED` 草稿再次确认 | `STATE_CONFLICT` | 不重复写入任务或学习计划。 |

## 非功能验收项

| 验收对象 | 检查方式 | 通过标准 |
|----------|----------|----------|
| Java 与 Maven 构建 | 在 `java-ai-assistant/` 执行 `mvn clean test` | 编译成功，默认单元测试全部通过。 |
| 默认测试隔离 | 检查测试配置和测试替身 | 默认单元测试不访问真实 DeepSeek、网络、API Key、用户文件或真实当前时间。 |
| 完整验证 | 执行 `mvn clean verify` | Surefire 测试通过，默认生命周期可生成构建产物。 |
| 覆盖率报告 | 执行 `mvn jacoco:report` 或检查 `target/site/jacoco/index.html` | JaCoCo 报告可生成或已存在，可用于复核白盒覆盖证据。 |
| 测试报告 | 检查 `target/surefire-reports/` | Surefire XML 和文本报告存在，测试数量、失败数和错误数可复核。 |
| 测试用例充分性 | 检查 `src/test/java/assistant/` 和 `docs/test-cases.md` | 覆盖核心业务逻辑、边界输入、异常路径、状态迁移、跨模块汇总和 AI 外部依赖失败处理。 |
| 控制台层职责 | 检查 `assistant.app` 与业务包 | 控制台层负责菜单、输入解析和展示，不承载核心业务判断。 |
| 服务返回语义 | 检查应用服务公开方法 | 成功返回可断言结果，失败返回稳定 `ErrorCode`，不依赖控制台文本判断业务结果。 |
| 仓储实现 | 检查 `InMemory*Repository` | 默认使用内存仓储；对外返回快照或只读视图，避免外部绕过服务修改内部状态。 |
| 可替换外部状态 | 检查 `TimeProvider`、`IdGenerator`、`AiClient`、`AiHttpTransport` | 当前时间、编号生成和 AI 外部调用可替换，单元测试可控。 |
| 配置安全 | 检查 README、环境说明和源码 | API Key 不硬编码，使用环境变量或 JVM 参数；未配置时给出稳定错误。 |
| 文档一致性 | 检查 README、环境说明、测试计划、测试用例、缺陷回归说明 | 文档描述与当前工程功能、命令和限制一致，不把可选集成验证写成默认单元测试前提。 |

## 不属于当前版本的明确边界

当前版本不要求实现以下能力，验收时不应将其作为默认通过条件：

- 账号登录、多用户、角色权限和云端同步。
- 数据库持久化、用户数据文件持久化、文件导入导出。
- 真实系统通知、后台定时提醒和移动端推送。
- 移动端界面、Web 图形界面、复杂桌面 GUI。
- 健康信息管理、联系人或常用信息管理。
- 训练模型、微调模型、私有模型服务和复杂智能体框架。
- 默认单元测试中的真实 DeepSeek 联网调用。
- 无 API Key 环境下的真实 AI 回复内容验收。

真实 DeepSeek API 连通性如需验证，应作为可选集成验收，要求网络可用并配置有效 `DEEPSEEK_API_KEY`。当前默认 Maven 单元测试通过不应依赖该条件。

## 验收执行建议

推荐按以下顺序执行最终验收：

1. 阅读 `README.md` 和 `docs/environment.md`，确认 Java、Maven 和可选 DeepSeek 配置。
2. 在 `java-ai-assistant/` 执行 `mvn clean test`，记录 Surefire 结果。
3. 执行 `mvn clean verify` 与 `mvn jacoco:report`，确认构建和覆盖率报告。
4. 启动 `assistant.app.Main`，按本文档的用户视角核心场景验收清单抽样操作。
5. 对异常场景至少覆盖每个业务模块一项输入错误和一项状态冲突或不存在记录。
6. 若配置真实 DeepSeek API Key，再单独执行可选 AI 集成验收；不把该结果作为默认单元测试通过前提。
7. 将失败项记录到缺陷回归文档，并在修复后重跑相关用例和核心回归集。
